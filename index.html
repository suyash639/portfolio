02Inference infrastructure

InferOpt

LLM routing gateway & inference engine.

Challenge
Monolithic LLM deployments bring runaway API cost, P99 latency spikes and GPU memory wasted on repeated prompt prefixes.
Approach
A gateway routes each request by latency and cost, reuses prefix KV-cache, coordinates speculative drafts and falls back across local and cloud endpoints.
  • Python
  • FastAPI
  • vLLM / Ollama
  • Redis
